# 🎬 Movie Explorer

A web-based movie exploration application that allows users to search and discover movies through a simple and user-friendly interface.

## 🚀 Features

- 🔍 Search for movies
- 🎬 View movie details
- ⭐ Display movie ratings
- 📖 View movie information and descriptions
- 🖥️ Modern frontend interface
- ⚡ Fast frontend development using Vite
- 🔗 Backend API using Flask
- 📱 Responsive design

## 🛠️ Technologies Used

### Frontend
- HTML
- CSS
- JavaScript
- React
- Vite

### Backend
- Python
- Flask

### Tools
- Git
- GitHub
- VS Code
